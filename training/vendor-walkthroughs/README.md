# Vendor walkthroughs: learn a task, then prove the result

Use official vendor demonstrations and reading to understand the product, then practice with an original fictional task. Each card asks for a prediction, a concrete work product, evidence and an explanation. The aim is an operator who can handle a changed situation, not merely repeat a sequence of clicks.

**Research reviewed:** September 19, 2026. Eight independent task cards; no vendor endorsement or certification. These cards have not been run with learners or in vendor tenants. Source-page review, existing technical tests and learner performance are different evidence.

## Run a card

1. **Predict.** Write your first explanation before opening the vendor material. Keep it so a reviewer can see what changed.
2. **Watch or read.** Follow the official link and selected chapter when one is verified. Record what you actually viewed/read and the source date/version. Use the linked text alternative if video or captions are unavailable.
3. **Practice.** Start with the supplied fictional evidence. Attempt an optional lab only when its separate environment and prerequisites already exist; otherwise record it as not attempted. The parent modules contain the detailed operating boundaries.
4. **Verify.** Compare your artifact with the answer guidance and expected evidence. Separate a supplied fictional observation from one you personally recorded. Keep partial, stale and unknown outcomes explicit.
5. **Teach back.** Explain the decision without replaying the steps, then answer the changed-scenario question. Record assistance honestly. This proposed assessment is not a measured retention result or vendor exam.

Use the editable [training record](../training-record-template.md). A person can finish viewing without completing practice, or complete a tabletop without demonstrating the technical task. Record those independently. Any vendor course achievement belongs in its own evidence field; these task cards cannot award it.

## Keep the source and the task current

Each card records its review date, publication/version information when observed, source-to-task relationship and revisit triggers. A portal update date is not necessarily the date of its videos. Google's admin hub includes mixed-age material; the 2025 Microsoft demo and 2024 n8n introduction are explicitly dated. The old n8n `video-courses` documentation URL returned Page Not Found, so the current education portal is the entry point here.

Before repeating a lab, reopen the authoritative task documentation and record differences in UI, licensing, privileges and version. If the prerequisite or expected behavior changed, pause that lab and update the task. Preserve the prior source/revision in the training record so observations remain interpretable.

The added value is our task framing, fictional fixture, evidence requirements, answer guidance and changed-scenario question. Videos remain hosted by their publishers; no full transcript, paid-course material or proprietary exam is copied. Store actual tenant evidence in a protected training workspace; only sanitized examples belong in this public repository.
