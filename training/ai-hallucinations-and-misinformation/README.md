# When the Assistant Is Confidently Wrong

A short module on spotting fabricated statistics, report titles, dates, and quotes in AI-assisted text, and tracing each claim to its primary source before it leaves the firm.

An assistant can hand you a market note that reads like finished work: a named report, a precise percentage, a quotation from a chief economist. In the AI at Work course you checked a draft against a packet. This module is about claims that point outside the packet, to sources nobody has opened yet.

Fluency is not evidence. The same process that produces a good sentence also produces a confident wrong one, and nothing in the text tells you which you have. I want you to leave with one habit: every number, title, date, and quote gets traced to its primary source before it goes out.

No AI account is needed. Work on paper or in a document, review the fictional packet, then compare with the example. If you try a prompt in an organization-approved tool, use only this packet. The suggested 9–12 minutes is a starting estimate; take longer if the checking needs it.

**Format:** Short module · **Track:** AI at work · **For:** Everyone who uses an AI assistant for research, summaries, or drafting. · **Before this course:** AI at Work
