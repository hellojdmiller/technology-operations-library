# Before You Scan

One short lesson on QR codes in emails, documents, and public places: why a code is a link you cannot read, how to preview it, and when to report instead of scanning.

A QR code is a link with the address hidden. When I see a link in an email I can at least hover over it and read where it goes. When I scan a code, my phone reads it for me and offers to open it, and most people tap without looking.

That is why codes turn up in phishing emails, in PDFs, and on stickers pasted over the real code on a parking meter. The code itself is harmless. The page it opens is the problem, and the phone that opens it is often a personal one with none of the firm's protections.

This module gives you one question to ask before scanning, a way to preview the destination, and two requests that are never legitimate by code in a work message. Work from the fictional packet on paper or in a document; you do not need to scan anything.

**Format:** Short module · **Track:** Security awareness · **For:** Everyone at the firm, whatever their role; no technical background is needed.
