## Lesson 1: Hang up and call back

**Outcome:** A callback script for any caller, plus a note of what the D1 and D2 callers asked for.

**Task:** Read D1 to D3. Write a two or three sentence callback script for either caller, then one line each for D1 and D2: what was asked for, and which number you would call back on.

**Deliverable:** A short script and two one-line notes, ready to send to IT.

- [ ] The script ends the call without arguing about who the caller is.
- [ ] The callback number comes from the directory, card, or statement, not the caller.
- [ ] Each note names the request: code, password, payment, or remote access.
- [ ] Neither note treats caller ID or a familiar voice as evidence.
