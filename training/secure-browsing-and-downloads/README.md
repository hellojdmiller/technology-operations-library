# Downloads, Extensions, and Pop-ups

A short module on where risky software really comes from, how to read a download page and an address bar, and what to do after a bad install.

Almost every bad install I have cleaned up started with someone doing something reasonable: looking for a PDF tool, reading an article, trying a colleague's recommendation. The trap was the route, not the person. This module is about noticing the route before the click, without needing to be a technician.

It takes about ten minutes and uses four fictional situations: a search advert on a lookalike domain, a fake browser update pop-up, a colleague's extension request, and the firm's approved-software excerpt. For each one you will decide to proceed, ask first, or report, and write down the single signal that decided it.

No tool account is needed. Work on paper or in a document and install nothing during the exercise. Everyone and every product in the packet is invented. Try the task first, compare with the example, then explain one decision aloud; saying why is what makes the habit hold.

**Format:** Short module · **Track:** Security awareness · **For:** Everyone at the firm who uses a browser, which is everyone.
