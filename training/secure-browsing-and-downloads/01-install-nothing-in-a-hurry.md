# 1. Install nothing in a hurry

Spot the ordinary routes bad software takes, and decide each case on one signal.

Suggested time: 8–10 minutes. Work on paper or in a document.

**Outcome:** A decision for each packet situation (proceed, ask first, or report) with the signal that decided it.

Read the [shared fictional packet](source-packet.md). Keep it available throughout the lesson.

Most bad software arrives by an ordinary route: the advert above the real search result, a page that says the browser needs updating, a free copy of a paid tool. Adverts can point anywhere, which is why criminals buy them for popular tools, and a page can do harm without a click. [S1](sources.md#s1), [S3](sources.md#s3)

Read the address bar first. The real site is the part before the first single slash; a lookalike adds words, changes the ending, or uses a hyphen the vendor never does. Browsers update through their own menu, never through a web page, and a real security warning never asks you to call. [S2](sources.md#s2), [S4](sources.md#s4), [S6](sources.md#s6)

An extension that can read and change all your data on all websites sees everything you see, email included. The warning means it could misbehave, not that it does, so the firm reviews these first. After a doubtful install: stop, tell the technology team, never run the cleaner the page offers. [S4](sources.md#s4), [S5](sources.md#s5)

## Worked example: Reading the address bar before the page

**Before**

The sponsored result says Official PDF Editor Pro and carries the vendor's logo. I click Download now.

**After**

The address is pdfeditor-pro-download.example.net; the vendor's site, one result down, is pdfeditorpro.example.com. The installer is 3 MB against the vendor's 180 MB. I close the tab and open the firm's catalogue, which has a PDF editor.

**Why:** The logo and the word official cost nothing to copy. The domain, the file size, and the approved route do not.

No. It is the same scam in different words: a web page cannot inspect your computer, and a real warning never asks you to call. Close the tab and report it. If you already called or let someone connect, tell the technology team now and change the passwords used on that device.

## Check one decision

A colleague clicked Update now in D2 and the download ran. The page now offers a free 'cleaner'. What should they do under D4?

- **A.** Run the cleaner, since the page found the problem and can remove it.
- **B.** Stop using the device, note what was clicked and when, run nothing else, and call or message the technology team.
- **C.** Delete the downloaded file and carry on, since nothing seems wrong.

<details>
<summary>Answer and feedback</summary>

The supported choice is **B**.

**A:** The cleaner comes from the page that showed the fake update: the second half of one scam. D4 says never run a cleaner the page offers; it hands the attacker a second install.

**B:** This matches D4 and keeps the evidence intact. Knowing the exact file and time lets the technology team check the device quickly.

**C:** Nothing seeming wrong is not evidence; the installer may already have done its work. Deleting it removes the trace the technology team needs. D4 asks for a report, not a quiet cleanup.

</details>
