# Identity provider

Directory and single sign-on services that authenticate people and issue tokens to applications.

Layer: [[Identity and devices]]. Segments: [[Enterprise]], [[SMB]]. Vendors: 16.

## Enterprise (16)

- [[Auth0]]: Auth0 is a developer-focused authentication and authorization platform for applications, owned by Okta.
- [[authentik]] (open source): authentik is an open-source identity provider with single sign-on, multi-factor authentication, and application proxying.
- [[Cisco Duo]]: Cisco Duo provides multi-factor authentication, device trust, and single sign-on.
- [[Frontegg]]: Frontegg provides user management and authentication infrastructure for software-as-a-service applications.
- [[Google Workspace]]: Google Workspace bundles Gmail, Calendar, Drive, Docs, Meet, and Chat with a cloud identity directory.
- [[JumpCloud]]: JumpCloud combines a cloud directory, single sign-on, device management, and conditional access in one platform aimed at small and mid-sized organizations.
- [[Keycloak]] (open source): Keycloak is an open-source identity and access management server supporting OpenID Connect, OAuth 2.0, and SAML.
- [[ManageEngine]]: ManageEngine is the IT management software division of Zoho, covering service desk, endpoint, and identity tools.
- [[Microsoft Entra ID]]: Microsoft Entra ID is the cloud directory and identity service behind Microsoft 365 and Azure sign-in, conditional access, and application federation.
- [[Okta]]: Okta provides cloud identity, single sign-on, lifecycle, and identity governance services for workforce and customer applications.
- [[OneLogin]]: OneLogin is a workforce identity and single sign-on service owned by One Identity.
- [[Ping Identity]]: Ping Identity sells enterprise single sign-on, federation, and customer identity software and services.
- [[Rippling]]: Rippling is a workforce platform combining HR, payroll, IT identity, device management, and spend management.
- [[Silverfort]]: Silverfort extends multi-factor authentication and identity threat protection to systems that cannot natively support them.
- [[WorkOS]]: WorkOS provides enterprise single sign-on, directory sync, and audit-log APIs that software vendors embed in their products.
- [[Zitadel]] (open source): Zitadel is an open-source identity management platform offered as a hosted service or for self-hosting.
