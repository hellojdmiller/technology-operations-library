# Secrets management

Storage and distribution of API keys, certificates, and machine credentials.

Layer: [[Security operations]]. Segments: [[Enterprise]], [[SMB]]. Vendors: 13.

## Enterprise (13)

- [[1Password]]: 1Password provides password vaults, passkey storage, and developer secrets management for individuals, families, and businesses.
- [[Akeyless]]: Akeyless provides SaaS secrets management and machine identity services.
- [[Bitwarden]] (open source): Bitwarden provides an open-source password manager and secrets manager available hosted or self-hosted.
- [[CyberArk]]: CyberArk provides privileged access management, secrets management, and identity security software.
- [[Doppler]]: Doppler is a hosted secrets manager for application configuration.
- [[External Secrets Operator]] (open source): External Secrets Operator synchronizes secrets from external managers into Kubernetes.
- [[GitGuardian]]: GitGuardian detects leaked secrets in source code and manages non-human identities.
- [[HashiCorp]]: HashiCorp develops Terraform, Vault, Consul, Nomad, and related infrastructure tools, owned by IBM.
- [[HashiCorp Vault]]: HashiCorp Vault stores, issues, and rotates secrets and certificates.
- [[Infisical]] (open source): Infisical is an open-source secrets management platform available hosted or self-hosted.
- [[OpenBao]] (open source): OpenBao is an open-source fork of Vault hosted by the Linux Foundation.
- [[Pulumi]] (open source): Pulumi provides infrastructure as code in general-purpose languages, plus secrets and configuration management.
- [[SOPS]] (open source): SOPS is an open-source editor for encrypted files that integrates with cloud key management services.
