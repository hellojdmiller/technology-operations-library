# Reusable prompt card

**Name, owner, and revision:** [Assign.]

**Job and audience:** [The outcome and who uses it.]

**Approved context and data scope:** [Sources, versions, permitted data classes, exclusions.]

**Host and delivery method:** [Chat, project instruction, native skill, or API; host/model details available.]

**Required capabilities:** [Browsing, file reading, calculations, local code, or none.]

**Authority:** [Allowed reads, writes, destinations, and actions requiring a separate decision.]

**Prompt body:**

```text
[Insert the task, context, constraints, output, acceptance criteria, and stop rule.]
```

**Evaluation:** [Cases, critical failures, reviewer, results, and date.]

**Known limits:** [Unsupported sources, missing tools, untested hosts, or excluded uses.]

**Change triggers:** [Model/tool/source/permission changes that require a new trial.]

**Retirement or replacement:** [How users find the current version and stop using the old one.]

Keep actual sensitive inputs, outputs, and evidence outside this resource repository. A prompt card records intended use; it does not grant permission or prove evaluation passed.
